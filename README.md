# BeautyCare-AI 💄

An AI-powered beauty care application that suggests the best hair care products based on customer problems.

## 🚀 Features
- Suggests the best products based on customer hair problems
- Provides perfect solutions for any hair-related issues
- Recommends only brand-specific products (not natural remedies)
- AI/LLM powered smart recommendations

## 🛠️ Tech Stack
- Python
- Django
- AI / LLM (Large Language Model)

## 📦 Setup & Installation
```bash
git clone https://github.com/UjvalThakor/BeautyCare-AI.git
cd BeautyCare-AI
pip install -r requirements.txt
python manage.py runserver
```

Now visit: http://127.0.0.1:8000
